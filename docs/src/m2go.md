# M2GO ![M2GO](img/m2_icon.png#right)

M2GO is a physical representation of the M2 Reference Design discussed in the previous sections. It comes preconfigured, tested, and ready to go. 

## What Can M2GO Do?
M2GO is a high-performance data acquisition system that can also do some control tasks. It also includes a number of advanced features including email alerts, local HMI, precision timekeeping, and comprehensive data recording.

In the standard "reference design" configuration, M2GO includes support for the I/O listed [here](hardware.md#hardware-reference-design). Many of these I/O can be allocated for different purposes, for example four of the eight analog inputs could be used for ±10v measurements while the other four inputs could be used for 4-20 mA current loop measurements. 

## Getting Started
M2GO will come configured running Ubuntu 22.04 and ROS2 Humble Hawksbill. It will come shipped in a heavy-duty IP68 stainless-steel enclosure designed for punishing environments. While the enclosure can withstand heavy rain and some strong water jets, it's not submersible. 

End users must supply compatible sensors.
